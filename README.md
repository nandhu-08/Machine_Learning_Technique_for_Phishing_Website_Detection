# Phishing Website Detection using Machine Learning

## Project Overview
This project is a machine learning-based web application developed to detect phishing websites. 
The system allows users to enter a website URL and predicts whether the website is phishing or legitimate.

The machine learning model is integrated into a Django web framework to provide real-time predictions through a user-friendly interface.

## Technologies Used
- Python
- Django
- Scikit-learn
- HTML
- CSS
- JavaScript
- Pandas
- NumPy

## Features
- Real-time phishing website detection
- Machine learning model integration with Django
- URL feature extraction and preprocessing
- User-friendly web interface
- Fast prediction results

## Machine Learning Workflow
1. Data collection from phishing dataset
2. Data preprocessing and feature extraction
3. Model training using machine learning algorithms
4. Model evaluation and testing
5. Integration with Django web application

## How to Run the Project

1. Clone the repository:
git clone https://github.com/yourusername/phishing-website-detection-ml.git

2. Install required libraries:
pip install -r requirements.txt

3. Run the Django server:
python manage.py runserver

4. Open in browser:
http://127.0.0.1:8000/
